⏱ TemporalAgent

IN: garage, histories(DataFrame), seed
OUT: predicted_available, rate, spatial_attention, temporal_references
actions: predict, names
temporal_agent.py

🗺 SpatialAgent

IN: garage, topk
OUT: most_similar garages, similarity matrix
actions: similarity, neighbors
spatial_agent.py

👤 HICAgent

IN: prediction, uncertainty, cost
OUT: trigger_human(bool), reason, risk
actions: evaluate, feedback, feedback_log
hic_agent.py

🚁 DroneFleetAgent

IN: targets, dwell_seconds, plan_id
OUT: plan(id, feasible), mission(state, mavlink telemetry)
actions: state, plan, start, cancel, mavlink_connect, mavlink_command
drone_agent.py

📷 DetectionAgent

IN: image (or None)
OUT: cars_detected, segmented, backend status
actions: detect, status
detection_agent.py

🔄 TransferAgent

IN: source DataFrame, target DataFrame
OUT: predictions per target, borrowed_from, similarity
actions: transfer_predict, transfer_gain
transfer_agent.py
